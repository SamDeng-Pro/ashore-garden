# 🌻 上岸花园 · 考公备考工作台

> GitHub: [SamDeng-Pro/ashore-garden](https://github.com/SamDeng-Pro/ashore-garden)

一款**单文件、零后端、开箱即用**的公务员考试备考工作台。把刷题打卡变成花园养成：每天打卡浇花，阳光值催开花朵，数据页实时诊断强弱项。

> 中文界面 · 手机优先（微信浏览器友好）· 数据完全存本地 · AI 能力可选

![技术栈](https://img.shields.io/badge/技术栈-纯HTML%2FCSS%2FJS-green) ![协议](https://img.shields.io/badge/协议-Apache%202.0-blue) ![后端](https://img.shields.io/badge/后端-无-orange)

## ✨ 功能一览

| 模块 | 说明 |
|---|---|
| 🌷 **花园养成** | 28 种花卉（玫瑰/向日葵/郁金香/波斯菊…），累计学习时长推动花种→发芽→花苞→盛放；打卡掉落阳光雨 |
| ✅ **打卡系统** | 两级考点标签点选 → 错题考点数量输入 → 自动汇总题量/错题/错误率 → 数据页实时联动 |
| 📊 **数据诊断** | 各模块学习量分布、正确率对比（含 80% 目标线）、薄弱模块 TOP3、时长分配环图 |
| 🎯 **目标追踪** | 里程碑目标 vs 打卡实际值实时对比（✅🟡🔴 三级状态） |
| 📅 **计划日历** | 月历视图，点日期弹当日计划详情；计划 vs 实际偏差分级提示 |
| 📝 **申论专区** | 历年真题 / 素材库 / 我的练笔 / 写作工具（规范词·金词·金句·模板） |
| 📰 **时政追踪** | 按日期分组、分类筛选的时事政治库（配套爬虫脚本每日更新） |
| 🤖 **AI 加持（可选）** | 申论手写图 OCR、AI 批改打分、打卡截图自动填数、计划偏差智能分析 |
| 🔄 **容错降级** | 没配 AI？自动降级为本地规则评分 + 确定性规则引擎，核心功能零依赖 |
| 📥 **历史补录** | 老玩家把之前刷过的题、写过的申论、模考分数批量录入（严格数字校验） |
| 🔔 **微信提醒** | 计划偏离严重时经 Server酱 推送微信（可选） |

## 🚀 快速开始

### 方式一：直接使用（推荐）

1. 下载 `garden_build/上岸花园v2.html`（或整个仓库后打开该文件）
2. 用浏览器打开，或部署到任意静态托管（见下）
3. 首次弹出新手向导：选目标考试 → （可选）配置 AI → 开始使用

> 数据保存在浏览器 localStorage，换设备/清缓存前记得用「设置 → 导出 JSON 备份」。

### 方式二：GitHub Pages 托管（获得一个公开链接）

```bash
# 仓库设置 → Pages → 选择分支 → Save
# 之后访问 https://<你的用户名>.github.io/<仓库名>/
```

微信里打开该链接即可使用，无需安装任何东西。

### 方式三：本地运行每日时政更新（可选）

```bash
cd knowledge_base/scripts
pip install requests bs4 lxml   # 爬虫依赖
python3 crawl_affairs.py         # 爬当日人民日报要闻
python3 build_affairs_deep.py    # 清洗+深度解析
python3 build_kb_embed.py        # 注入前端 HTML
```

## 🤖 配置 AI（可选，强烈建议）

任何兼容 **OpenAI 接口格式**的大模型服务都可以：智谱 / DeepSeek / Kimi / 通义…

1. 首页右上角 ⚙️ → AI 接口，或首次向导中配置
2. 填三样：Base URL（完整 `chat/completions` 地址）、模型名、API Key
3. 点「保存并验证」——验证通过即可解锁全部 AI 功能

以智谱为例：[open.bigmodel.cn](https://open.bigmodel.cn) 控制台 → API Keys → 创建并复制。**Key 只存在你自己浏览器的本地存储里，不上传任何服务器。**

| AI 功能 | 无 Key 时的降级方案 |
|---|---|
| 申论批改 | 本地规则评分（切题/结构/表达/规范词四维度） |
| 打卡截图识别 | 手动填写（数量输入框本身支持手动） |
| 计划偏差分析 | 确定性规则引擎（完成度加权算法） |
| 申论手写图识别 | 无降级，需手打文字 |

## 🏗️ 架构

```
单页应用（无框架、无构建工具、无后端依赖）
├── garden_build/
│   ├── new_part1~7.html   # 7 个分片：样式/骨架/数据层/SVG/渲染/渲染2/事件
│   ├── 上岸花园v2.html     # 合并产物（7 分片 cat 合并 + 知识库注入）
│   └── e2e_test.js        # 43 项真浏览器端到端测试（puppeteer-core）
└── knowledge_base/
    ├── data/              # 时政/申论真题/标签体系/学习计划 JSON
    └── scripts/           # 时政爬虫、数据构建、前端注入 12 个 Python 脚本
```

**数据层设计**：优先尝试 WorkBuddy 页面 SDK 云端同步（可选增强），不可用时无缝降级 localStorage——普通部署下就是纯本地应用。三张逻辑表：打卡记录 / 学习记录（统计来源）/ 任务清单。

**测试**：`node garden_build/e2e_test.js`（需本机 Chrome + `npm i puppeteer-core`），覆盖向导、打卡全流程、AI 降级链、补录校验等 43 项。

## 🔐 隐私设计

- **零上传**：所有学习数据存本地浏览器；AI Key 只存本地
- **无追踪**：没有任何统计/上报代码
- **BYOK**：AI 用自己的 Key，微信提醒用自己申请的 [Server酱](https://sct.ftqq.com) SendKey
